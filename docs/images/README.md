## 더 추가하면 좋은 장면 (선택)

새 캡처를 이 폴더에 넣으면 문서에 추가할 수 있습니다.

| 추천 파일 이름 | 장면 |
|---|---|
| drag-to-cell.png | 다른 창을 끌어 셀 위에 올렸을 때 셀 테두리가 파랗게 바뀐 모습 |
| same-kind-menu.png | 같은 종류의 창 모두 배치 ▸ 프로그램 ▸ 탭/좌우/상하 하위 메뉴 |
| multi-arrange.png | 여러 프로그램 한꺼번에 배치 대화상자 |
| split-count.png | 좌우로 나누기를 Ctrl+클릭했을 때 칸 수 입력 창 |
| fullscreen-toast.png | 전체 화면에서 세트를 바꿨을 때 위쪽 가운데 알림 |
| close-cells.png | 셀 여러 개 선택해서 닫기 대화상자 |
| window-picker.png | 실행 중인 창 배정 대화상자 |

## 캡처 요령

- `Win + Shift + S` → 창 캡처 또는 사각형 캡처 → 붙여넣기 후 PNG 로 저장
- 개인 정보(이메일, 파일 경로, 회사 문서 등)가 보이지 않게, 메모장 같은 예시 창으로 찍는 것을 권장합니다.
