# 사용법 설명용 화면 캡처

이 폴더에 넣은 이미지는 README.md 와 사용법.md 에서 사용합니다.
파일 이름은 자유롭게 정해도 됩니다. 아래 이름을 쓰면 정리가 쉽습니다.

| 파일 이름 | 장면 |
|---|---|
| 01-overview.png | 메인 창 전체: 세트 줄 + 여러 셀로 나눈 화면에 창이 들어 있는 모습 |
| 02-empty-cell.png | 빈 셀 (안내 문구가 보이는 상태) |
| 03-context-menu.png | 셀 컨텍스트 메뉴가 열린 모습 |
| 04-split-count.png | 좌우로 나누기를 Ctrl+클릭했을 때 칸 수 입력 창 |
| 05-drag-to-cell.png | 다른 창을 끌어 셀 위에 올렸을 때 셀 테두리가 파랗게 바뀐 모습 |
| 06-same-kind-menu.png | 같은 종류의 창 모두 배치 ▸ 프로그램 ▸ 탭/좌우/상하 하위 메뉴 |
| 07-multi-arrange.png | 여러 프로그램 한꺼번에 배치 대화상자 |
| 08-tabs.png | 탭으로 묶인 셀 |
| 09-sets.png | 세트 줄 또는 세트 메뉴 |
| 10-fullscreen-toast.png | 전체 화면에서 세트를 바꿨을 때 위쪽 가운데 알림 |
| 11-close-cells.png | 셀 여러 개 선택해서 닫기 대화상자 |
| 12-window-picker.png | 실행 중인 창 배정 대화상자 |

## 캡처 요령

- `Win + Shift + S` → 창 캡처 또는 사각형 캡처 → 붙여넣기 후 PNG 로 저장
- 개인 정보(이메일, 파일 경로, 회사 문서 등)가 보이지 않게, 메모장 같은 예시 창으로 찍는 것을 권장합니다.
- 메뉴가 열린 장면은 `Win + Shift + S` 를 누르기 전에 메뉴를 먼저 열어 두면 됩니다.
